# Pad 轻量播控坞返工与 QC

日期：2026-09-03  
范围：Pad 播放 / 暂停等控制区视觉与交互；不修改电视端媒体内容、目录映射或现场硬件拓扑。

## 设计结论

- 参考图只作为控制语言：圆形核心、深色背景、冷色发光和左右切换关系。
- 不复制参考图的人像、歌曲列表、随机或循环功能。
- Pad 仍为纯控制端；电视 / 播放盒子仍是唯一视频播放端。
- 用户否决的三块底部卡片、大半圆 HUD、叠加光环与高饱和按钮已经移除。
- 播放 / 暂停为 68 × 68 px 单层发光圆形核心。
- 上一项为 56 × 56 px；下一项为 128 × 56 px，保留更大的中文触控面积但降低视觉重量。
- 进度保持只读；原速 / 2× / 4×与静音降为右侧次级控制。
- 控制模式改用干净的星空底图，不再把带旧 UI 的效果图当背景重复显示。
- 目录与播控坞已由实色深蓝改为通透玻璃：37–38% 冷色底、30 px 背景模糊、145–150% 饱和度补偿、1 px 冷色边缘与单层斜向内反光；玻璃后方星云仍可见。
