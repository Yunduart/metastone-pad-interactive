# TV 待机画面｜12 秒循环动效规范 v1.0

状态：视觉与程序预览基线；待 REDMI 电视实机、播控盒样机和现场亮度复核后冻结。本文不构成采购下单或生产放行。

## 1. 画面目标

- 输出比例：16:9；设计与验收主尺寸为 3840 × 2160。
- 视觉方向：沿用现有不对称星系构图。METASTONE 核心位于左中区域，七颗星球按原有非均匀间距分布在主环/外环上，不重新平均排列。
- 画面层级：深黑靛星空 → 轨道与远近星球 → 左侧品牌核心 → 右下待机文案 → 右上播控状态。
- 电视端只承担展示和播放，不提供可拖拽或可点击的访客交互。
- 待机提示：`成果案例 · 产品介绍 / 请在 Pad 端选择内容`。

## 2. 12 秒无缝循环

| 时间 | 动作 | 视觉幅度 |
|---|---|---|
| 0–3 秒 | 建立默认构图；核心与星球保持原位，星体自转、星尘缓慢漂移 | 低 |
| 3–6 秒 | 主环/外环产生极轻的空间摆动；核心随同一世界坐标作小幅视差 | 低 |
| 6–9 秒 | 星尘近层与远层形成不同速度的横纵视差，核心呼吸光达到峰值 | 低至中 |
| 9–12 秒 | 所有角度、位移、亮度回到第 0 秒精确状态 | 低 |

- 周期函数使用正弦往返，12 秒首尾值一致，不出现跳帧、硬切或位置突变。
- 星系方位摆幅约 ±0.052 rad；轨道俯仰约 ±0.012 rad；核心水平视差约画宽 ±0.6%，垂直视差约画高 ±0.35%。
- `prefers-reduced-motion` 启用时取消位移循环，只保留静态待机画面。

## 3. 待机与媒体切换

- 首个有效播放命令：待机层在 300–500 ms 内淡出，媒体层在 500–720 ms 内淡入；不经过黑屏。
- 播放结束、退出、连接恢复失败回首页：回到同一待机基准画面。
- 视频缺失：进入明确标记的测试槽，不用截图或封面冒充已交付视频。
- 浏览器首次启用：保留一次电视端“启用电视播放”操作，用于满足全屏/自动播放策略；之后由 Pad 控制。

## 4. 媒体与设备建议

- 动态待机备选导出：H.264 MP4、30 fps、无音频、12 秒、3840 × 2160；码率在 REDMI 电视和播控盒样机上实测后冻结。
- 当前 WebGL 待机可直接运行在播控盒浏览器；若样机性能或长期稳定性不足，按本规范预渲染为 H.264 循环视频。
- 电视精确型号、HDMI 规格、色彩模式、亮度、过扫描、休眠策略和开机输入源仍需现场读取铭牌与系统设置。
- 两台电视各配置一台独立播控盒/迷你主机；Pad01 与 Pad02 的 controller/channel/target endpoint 必须隔离。

## 5. 现场验收

- 连续循环 30 分钟无可见跳点、闪黑、撕裂或浏览器控件露出。
- 3 米观看距离能识别品牌、`成果案例 · 产品介绍` 与 Pad 操作提示。
- Pad 触发播放到电视首帧、暂停、1×/2×/4×、退出回待机均需双端实测。
- 断网、播控盒重启、电视断电恢复后应自动回到待机页；不得停在桌面、浏览器错误页或系统设置页。
