# 是石科技 · 双板块视频播控互动台 V1

> 当前版本仅用于客户体验测试，不作为验收依据或生产放行版本。现阶段只验证单 Pad → 单 TV 的局域网体验链路，不得据此认定双 Pad → 双 TV 固定通道隔离已经完成。

独立于 ROMS CPU / GPU 系统的 Xiaomi Pad 8 Pro 3:2 横屏点播程序。总览采用 Three.js / WebGL 实时轨道场景，并在同一套播控逻辑中承载 `成果案例` 与 `产品介绍` 两个内容板块。本期测试环境由 Xiaomi Pad 播控端与电视播放端组成。

## 内容板块

- `成果案例 / SUCCESS CASES`：大模型、科研院所、高端制造、海洋模拟、航空航天、互联网、AI FOR SCIENCE。
- `产品介绍 / PRODUCT INTRODUCTION`：九个产品节点、十一部源影片记录；正式文件仍按内容槽位逐项接入。

## 交互

- 顶部双板块开关：淡出当前星系内容，再装载目标目录；不复制程序、不打断整套 WebGL 播控逻辑。
- 拖动空白区域：旋转完整三维星系；选中连接线上的小飞船沿曲线飞向当前内容星球。
- 单击任意内容星球：聚焦该星球，并由星球位置展开全屏影片。
- Pad 播放页：支持播放 / 暂停、原速 / 2× / 4×、静音、上一视频、下一视频和返回总览；进度仅显示播放端同步状态，不允许拖动。
- Pad 的上述指令通过局域网控制服务同步给电视端；电视端从品牌待机画面淡入对应视频，停止后淡回待机。
- Pad 每 500ms 回传真实播放状态；控制服务维护权威进度锚点、播放实例和命令序号，电视端按偏差进行柔性追帧或强制对时。
- 20 秒无操作：进入自动巡航，仅轮换高亮，不自动播放影片。
- 播放完成：显示重播 / 下一视频 / 返回总览，8 秒无操作后自动回到星图。

当前 16 个视频槽位中仅 2 个已放入测试素材，其余 14 个槽位会显示明确的演示/缺失提示；正式视频的替换规则见 `public/videos/README.md`，小米平板部署流程见 `docs/Xiaomi_Pad_部署说明.md`。

## 本地运行

```bash
npm install
npm run dev
```

生产验证：

```bash
npm run build
npm run test:sites
```

局域网平板预览：

```bash
npm run preview:pad
```

本期 Pad / TV 双端测试环境：

```bash
npm run testenv:prepare
npm run testenv
```

- Pad：`http://<主机IP>:4175/pad`
- 电视：`http://<主机IP>:4175/tv`
- 视频槽位检查：`npm run content:check`
